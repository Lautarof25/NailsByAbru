# 🌸 Studio Verdini - NailsByAbru - Página Web de Manicura

## 📖 Descripción
Este proyecto consiste en el desarrollo de una página web gratuita para **Studio Verdini**, un salón de manicura local.  
La iniciativa busca **potenciar la presencia digital de emprendimientos locales**, ofreciendo un sitio web bonito, limpio y funcional que refleje la calidad de los servicios y trabajos realizados.

## 🎯 Objetivos
- Brindar visibilidad online al salón de manicura.
- Mostrar de manera clara y estética los **servicios ofrecidos**.
- Exhibir una galería con los **trabajos realizados**.
- Facilitar el contacto y la ubicación del negocio.
- Crear una base sólida para futuras mejoras digitales.

## 🛠️ Tecnologías utilizadas
El proyecto se desarrollará con tecnologías básicas, sin frameworks, para mantenerlo ligero y accesible:
- **HTML5** → estructura semántica del sitio.
- **CSS3** → estilos visuales, diseño limpio y moderno.
- **JavaScript** → interactividad básica (animaciones, formularios).
- **IA como apoyo** → generación de contenido, optimización de imágenes y textos.

## ✨ Características principales
- **Diseño minimalista y elegante**, adaptado a la estética de un salón de manicura.
- **Responsive Design**: el sitio se verá bien en computadoras, tablets y celulares.
- **Galería de imágenes** optimizada para mostrar trabajos realizados.
- **Sección de servicios** con descripciones claras y atractivas.
- **Formulario de contacto** simple y funcional.
- **Mapa de ubicación** para facilitar la llegada de clientes.
